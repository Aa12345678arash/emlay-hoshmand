# بسته صوتی آفلاین املای هوشمند پنجم

فایل‌های MP3 فارسیِ از پیش تولید و تأییدشده در این پوشه قرار می‌گیرند. موتور ابتدا manifest را بررسی می‌کند؛ اگر فایل محلی وجود داشته باشد، آن را بدون اینترنت پخش می‌کند و در غیر این صورت به Android TTS و سپس Web Speech برمی‌گردد.

## شناسه‌ها
- واژه: `word:<lessonId>:<متن دقیق واژه>`
- جمله: `dictation:<passageId>:<شماره جمله از صفر>`

نمونه مسیر: `audio/lesson-01/dictation/l1-a-01.mp3`

فقط فایل‌هایی به manifest اضافه شوند که متنشان مقابله شده، تلفظ و مکثشان شنیداری تأیید شده و مجوز استفاده از صدا روشن است. کلید API یا URL سرویس آنلاین نباید داخل APK قرار گیرد.

**وضعیت فعلی:** manifest عمداً خالی است؛ هنوز فایل صوتی اختصاصی تولید و تأیید نشده است. زیرساخت آماده اتصال فایل است، اما صدای آفلاین اختصاصی تا زمان افزودن فایل‌های واقعی فعال نیست.
